## Running the coefficient calculator

This repository contains a Tkinter-based application for working with tee
sketches and airflow graphs. To start the program locally:

1. Install the [Pillow](https://python-pillow.org/) imaging library:

   ```bash
   pip install pillow
   ```

2. Launch the GUI:

   ```bash
   python main.py
   ```

Older project archives are supported and will be upgraded automatically when
loaded.
